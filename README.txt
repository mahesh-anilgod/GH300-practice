GH-300 QUIZ APP V2

Open index.html in Edge, Chrome, or Firefox. No server is required.

FEATURES
- Auto-save after each submitted answer
- Resume saved sessions
- Last 30 completed attempts in history
- Bookmark/unbookmark questions
- Mock exams of 25, 50, or 100 questions
- Review incorrect answers
- Shuffle and dark mode

STORAGE
Progress, history, and bookmarks use browser localStorage. They remain after closing the browser, but do not sync across browsers/devices and are removed if site data is cleared.

GITHUB PAGES
Upload the contents of this folder to a GitHub repository and enable GitHub Pages. Keep index.html at the published root.

NOTE
This build contains 100 questions using source Q1-Q58 and Q60-Q101. Check answer keys against current official documentation before relying on them as authoritative.
